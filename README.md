# Nova Mart Promotional Campaign Analysis

## 📊 Project Overview

This project analyzes the impact of promotional campaigns on sales performance at Nova Mart using Python.

## 🎯 Objectives

* Evaluate campaign effectiveness (Diwali vs Sankranti)
* Analyze promotion types (BOGOF, cashback, discounts)
* Identify city-wise and product-level performance

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn)
* Jupyter Notebook

## 📈 Key Insights

* Diwali campaign outperformed Sankranti with a significant revenue boost (~+79M)
* BOGOF and cashback offers drove the highest sales volume
* Customer behavior favors value-based promotions over standard discounts

## 📂 Files

* `Campaign_Performance_Analysis_Nova_Mart.ipynb` → Full analysis notebook

## 🚀 Conclusion

Promotional strategy and timing play a critical role in maximizing revenue and customer engagement.
